Space-time merge planner

What
Real-time gap-based merge planning for autonomous highway driving
Where
IVALab, Georgia Tech, with Prof. Patricio Vela
When
Jun 2026 – present
Stack
Python, MATLAB, HighwayEnv, ProcessPoolExecutor
  • Ported an offline MATLAB gap-based planner to a real-time, closed-loop Python controller for HighwayEnv. It plans over a 12 s space-time window in under 4 ms per decision, about 7× faster than an MPC baseline.
  • Added a CBF-QP safety filter that keeps lane-change trajectories physically feasible, so the car can merge continuously instead of stopping to wait.
  • Prototyped acceleration-aware prediction of surrounding vehicles: crash rate −22%, prediction error −55% to −74%, and 8% more merges per episode across 500 paired episodes (p < 0.0001).
  • Built a seeded harness that benchmarks 8 planners on crash, merge, and runtime metrics, and parallelized it across 8 workers: 5 min down to 45 s.
  • Wrote a shared JSON scenario format so the MATLAB and Python planners run identical cases, which exposed and fixed a port bug that dropped valid merge options below the n+1 bound.

ML classification workflow

What
Flagging at-risk students from behavioral and demographic data
When
Nov 2025 – Jan 2026
Stack
Python, scikit-learn, pandas, NumPy, joblib
  • Built a scikit-learn Pipeline over ~500 student records: median imputation, scaling, and one-hot encoding chained so cross-validation can't leak data.
  • Compared Logistic Regression, Random Forest, and Gradient Boosting with stratified 5-fold cross-validation.
  • Only ~20% of students were at-risk, so the first models passed 90% accuracy by never flagging anyone. Class-weighted training and a decision threshold lowered from 0.5 to ~0.35 fixed it: ~70% accuracy with much better recall on at-risk students.
  • Serialized the final pipeline with joblib and documented why its threshold differs from the default.
